\section*{Input}

The input begins with one line containing $N$, $M$, $K$, $A$, $B$ ($2\le N,M\le 10^5$,$0\le K\le
100$,$0\le A,B<N$) separated by spaces. There are then $M$ lines containing $a_i$,$b_i$,$c_i$ (
$0\le a_i,b_i<N$,$-10^9\le c_i\le 10^9$) separated by spaces, denoting an edge from node $a_i$ to
node $b_i$ with cost $c_i$.

\section*{Output}

Output a single integer $C$, the smallest possible total cost on a path from $A$ to $B$ in the
graph. If such cost can be made arbitrarily small, output instead "NEGATIVE INFINITY". If no such
path exists, output "POSITIVE INFINITY".
