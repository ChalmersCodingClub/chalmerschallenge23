\problemname{Pub crawl}

Fritjof is going to his first ever pub crawl. Since he doesn't want to go all out on his very first
time, he's decided that he's only going to visit a single pub. As he likes all pubs equally much he
will stay at each pub for an equal amount of time regardless of which pub it is. To still be able to
brag about the amount of time he's been on the pub crawl, he wants to visit the pub with the longest
queue time. Which pub should Fritjob go to?

\section*{Input}

The first line of input contains an integer $N$, the amount of pubs Fritjob can choose between. On
each of the following $N$ rows there will be three values: $p$, the name of the pub; $k$, the amount
of people in queue; and $t$, the amount of time for one person to get in.

\section*{Output}

Print $p$, the name of the pub Fritjof chooses. If there are multiple pubs with the same queue time,
print the first suitable pub in the list.
